      43             :  * relation and can be used to build a restriction clause for that rel.
      44             :  * For example consider

      46             :  * We can transform this into
      47             :  *              WHERE ((a.x = 42 AND b.y = 43) OR (a.x = 44 AND b.z = 45))
      48             :  *                      AND (a.x = 42 OR a.x = 44)
      49             :  *                      AND (b.y = 43 OR b.z = 45);

      51             :  * perhaps as index qualifications, and in any case reducing the number of
      52             :  * rows arriving at the join.  In essence this is a partial transformation to
      53             :  * CNF (AND of ORs format).  It is not complete, however, because we do not
      54             :  * unravel the original OR --- doing so would usually bloat the qualification
      55             :  * expression to little gain.

      57             :  * The added quals are partially redundant with the original OR, and therefore
      58             :  * would cause the size of the joinrel to be underestimated when it is finally
